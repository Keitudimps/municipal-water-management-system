# AquaAlert

To run the already-installed app on Windows, follow
[Start PostgreSQL and Backend.txt](./Start%20PostgreSQL%20and%20Backend.txt).
In short: check PostgreSQL is running, start the backend, then run Flutter in a
second PowerShell terminal. No setup or account-creation steps are needed for
normal startup.

- Citizen reporting: <http://localhost:5000/#/>
- Operations dashboard: <http://localhost:5000/#/dashboard>
- Backend health check: <http://localhost:4000/health>
